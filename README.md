# ScreenTime2000

Downloads for **ScreenTime2000**, the add-on for [Choremaster2000](https://choremaster2000.web.app) that limits how
long kids can use a Windows, Mac or Linux computer. Adults set the limits and add time from the Choremaster app.

**To install it, go to [choremaster2000.web.app/download](https://choremaster2000.web.app/download) on the kids'
computer** and follow the steps for that kind of computer. Once installed, it keeps itself up to date.

Each [release](https://github.com/clearsparkapps/screentime2000/releases) holds one set of versions:

- `ScreenTimeSetup.exe` or `ScreenTime.zip`: Windows 10 and 11
- `install-mac.sh`: Mac (macOS 12 or newer)
- `install-linux.sh`: Linux with systemd and Python 3.8 or newer

Every download is signed by Clear Spark Apps; the installers and the updates refuse anything that isn't.
